# Skills для автоматизации тестирования

Набор skills (инструкций и скриптов) для LLM-ассистента в проекте автотестов на Java 17, Groovy и Spock.
Skills рассчитаны на слабые и средние модели (Qwen ~35B): всю детерминированную работу делают скрипты, модель только запускает их и показывает результат.

## Skills

| Skill | Что делает |
|-------|------------|
| [java-autotest-review](skills/java-autotest-review) | Ревью Spock-спецификаций и Java-тестов по чеклисту: sleep, тест без проверки, хардкод URL и паролей, зависимость тестов, static WebDriver, проглоченные исключения. Выдаёт таблицу «пункт, строка, проблема, исправление». |

## Структура

```
skills/
└── <skill-name>/
    ├── SKILL.md          # инструкция для модели (коротко, по шагам)
    ├── scripts/          # скрипты, которые делают основную работу
    ├── references/       # доп. материалы, читаются только при необходимости
    └── evals/            # тестовые файлы и ожидаемые результаты
```

## Использование

**С моделью.** Подключите `SKILL.md` к контексту модели и дайте ей инструмент запуска команд. Модель вызывает скрипт и возвращает его вывод.

**Без модели.** Скрипты работают самостоятельно, их можно запускать вручную, в CI или в pre-commit хуке:

```bash
python skills/java-autotest-review/scripts/prescan.py src/test/groovy/LoginSpec.groovy
```

Требования: Python 3.8+, сторонние библиотеки не нужны.

## Принципы для новых skills

- Один skill — одна узкая задача.
- Всё, что можно посчитать кодом (номера строк, поиск, шаблонные исправления), делает скрипт, а не модель.
- `SKILL.md` — до 50 строк: шаги, жёсткий формат ответа, явный запрет добавлять лишнее.
- Не оставляйте модели заглушки для заполнения: слабые модели с этим не справляются.
- Каждый skill содержит `evals/` с примерами и ожидаемым выводом. После изменения прогоните их на целевой модели.
