# Ревью Spock-спецификации по чеклисту

Скрипт делает всю проверку и пишет черновик ответа. Твоя задача — заменить заглушки и вывести черновик.

## Шаги

1. Запусти: `python scripts/prescan.py <файл>`. Несколько файлов передай одной командой через пробел.
2. Возьми текст между `=== ЧЕРНОВИК ОТВЕТА ===` и `=== КОНЕЦ ЧЕРНОВИКА ===`.
3. Если под черновиком есть список «ЗАПОЛНИ ЗАГЛУШКИ», замени в черновике каждую заглушку в угловых скобках на код. Подсказка к каждой заглушке есть в этом списке.
4. Выведи черновик. До и после него ничего не пиши.

## Как заполнить заглушки

- `<УСЛОВИЕ>` — что должно стать готово. Возьми объект из строки-подсказки и проверь, что он отображается.
  Подсказка: `driver.findElement(By.id('profile')).click()` → `driver.findElement(By.id('profile')).displayed`
- `<ПРОВЕРКА>` — условие на результат действия.
  Подсказка: «условие на result, строка 45: `client.get(path: '/reports')`» → `result.status == 200`
- `<СОЗДАТЬ ДАННЫЕ>` — код, который создаёт значение поля.
  Подсказка: `userId = api.createUser()` → `api.createUser()`
  Если справа от `=` стоит переменная теста (например, `resp.data.id`), напиши вызов метода с понятным именем: `createOrder()`.

## Правила

- Меняй только заглушки. Номера строк, пункты, проблемы и готовый код не трогай.
- Не добавляй свои замечания и строки таблицы.
- Если черновик — это одна строка «Нарушений по чеклисту не найдено.», выведи только её.
- Если скрипт не запускается, открой `references/manual.md` и следуй ему.
