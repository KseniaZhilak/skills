# Ревью Spock-спецификации по чеклисту

Всю проверку делает скрипт. Он печатает готовый ответ.

## Шаги

1. Запусти скрипт. Несколько файлов передай одной командой через пробел:
   `python scripts/prescan.py <файл>`
2. Выведи пользователю вывод скрипта целиком, без изменений.

## Правила

- Ничего не меняй в выводе скрипта: ни строки таблицы, ни номера, ни код.
- До и после вывода скрипта ничего не пиши.
- Если скрипт не запускается, открой `references/manual.md` и следуй ему.
